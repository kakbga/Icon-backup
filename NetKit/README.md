## 使用指南 · Usage

- **一键导入**：在[图标站](https://kakbga.github.io/Icon-backup/main/NetKit/?lang=zh#icon-subscription)点击 Quantumult X、Loon 或 Stash 的图标。
- **订阅图标集**：点击 Surge / Egern / FlClash 的组合按钮复制[订阅链接](https://kakbga.github.io/Icon-backup/main/NetKit/surge-icons.json)，再粘贴到客户端的图标集设置中。
- **引用单个图标**：从图标站复制 Raw 链接，用于 Mihomo 等支持图标 URL 的配置或界面。路径区分大小写。

Mihomo 策略组示例：

```yaml
icon: https://raw.githubusercontent.com/kakbga/Icon-backup/main/NetKit/icon/groups/Planet.png
```
